# MoonJSONC

MoonBit source-preserving JSON/JSONC tooling for configuration automation,
editor integrations and reviewable batch changes. Development is in progress.

Core scope: token scanning, tolerant trees and diagnostics, source/path lookup,
visitor events, comment stripping, document/range formatting, local structural
edits, validated edit application and transactional batches.

Targets: JavaScript and Wasm GC. Toolchain: MoonBit 0.10.14+7d59c7ec9.

License: MIT. Implementation and verification use AI assistance.
